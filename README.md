# Stephen Ngigi - Personal Portfolio

Welcome to my personal portfolio website! 

This project is a simple and responsive personal portfolio created using **HTML and CSS**. It introduces me, provides information about my interests in software development, and includes my contact details and GitHub profile.

My name is **Stephen Ngigi**, a software development student at **KCA University** with a passion for web development.

##  Features

- Personal introduction
- Profile picture
- About Me section
- Projects section
- Contact information
- Email contact link
- GitHub profile link
- Responsive design
- Modern navigation menu
- Hover effects
- Mobile-friendly layout

##  Technologies Used

- **HTML5** – Used to structure the website.
- **CSS3** – Used to style and design the website.
- **Responsive Design** – Used to make the website work on different screen sizes.
